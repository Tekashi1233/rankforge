# RankForge

Free, no-signup SEO and writing toolkit that runs entirely in the browser. Live at [https://rankforgetool.com](https://rankforgetool.com).

## Why this exists

Most SEO tools are paywalled or require signup. RankForge gives freelancers, students, and small site owners free, instant tools that run in the browser — nothing you type is sent to a server.

## Tools

- **GEO Score Checker** — Get a 0–100 GEO readiness score for any content based on answer-first structure, stats and quotability for 2027 AI search.
- **Schema Markup Generator** — Create valid JSON-LD for Article, FAQ, Organization, Product and LocalBusiness.
- **XML Sitemap Generator** — Paste URLs and download a valid sitemap.xml for Google and Bing.
- **Meta Tag Generator** — Title, description and Open Graph tags with a live Google preview.
- **Word & Character Counter** — Words, characters, sentences and reading time.
- **Slug Generator** — Clean, SEO-friendly URL slugs from any title.
- **Robots.txt Generator** — Build crawl rules and download robots.txt.
- **llms.txt Generator** — Create an llms.txt file with clear AI usage and citation instructions.
- **Keyword Density Checker** — See your most used words and their share of the text.
- **Readability Score Checker** — Flesch Reading Ease and grade level for any text.
- **Text Case Converter** — Convert text to upper, lower, title or sentence case.
- **Password Generator** — Create strong random passwords in your browser.
- **Lorem Ipsum Generator** — Generate placeholder text for designs and mockups.
- **AI Readiness Checker** — Check how ready your page is for AI search answers.

## Tech

Plain HTML/CSS/JS, hosted on Cloudflare Pages. SEO and AI-search ready (sitemap, RSS, llms.txt).
