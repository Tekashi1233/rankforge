## Method notes

- Audit scripted in Python (`~/workspace/goals/rankforge-weekly-audit/hidden_files/audit-2026-11-27.py`,
  adapted from the 2026-11-20 script): per-page title/meta/canonical/OG/Twitter/heading/image/footer/JSON-LD
  extraction for all 55 pages with `html.parser` (real JSON-LD blocks only — tool JavaScript
  strings are not parsed); sitemap vs file inventory; RSS vs `datePublished`; word counts;
  internal-link target resolution (relative hrefs resolved); duplicate-content Jaccard
  similarity; `curl` live checks for home, sitemap, RSS, robots.txt, ads.txt, llms.txt,
  one tool, one blog post, both external hosts, and redirect hop traces for `.html`,
  `http://`, `www` and trailing-slash variants. Extra checks this week: llms.txt URL
  resolution against disk (21 tools / 25 posts, 0 missing), hero-image audit (alt, lazy
  loading, file size, og:image match), viewport meta on all pages, font loading pattern
  on all pages, AdSense tag presence on all live pages, hand-check of the highest-similarity
  pairs, and a Node smoke test of the UTM builder's inline `build()` logic.
- Word counts include navigation/footer text, so article text alone is shorter than the
  figures quoted; the "under 800 words" flag is therefore conservative.
- No facts, statistics or tool features were invented. All new copy is original and derived
  from the pages' own meta descriptions.
