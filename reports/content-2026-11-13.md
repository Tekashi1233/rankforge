## What was added and why

### Tool: URL Encoder / Decoder
- URL: https://rankforgetool.com/tools/url-encoder-decoder
- File: tools/url-encoder-decoder.html

Why this tool: of the candidates, URL Encoder / Decoder was the most distinct from the 18 existing tools. The closest neighbour is the Slug Generator, but the two do different jobs: the slug tool turns a title into a clean lowercase hyphenated slug, while this tool percent-encodes or decodes any URL or text. People search for URL encoding a lot (spaces, Arabic text and query strings breaking shared links), and the whole thing runs in plain browser JavaScript with no server. Modes: encode a component (encodeURIComponent), encode a whole URL (encodeURI), decode (decodeURIComponent). Live as-you-type, character counts, a warning when input looks already encoded (double-encoding turns %20 into %2520), copy/clear/example buttons, and a table showing the encodeURI vs encodeURIComponent difference.

## Test results

Tool logic tested with Node (same encode/decode functions as the page):
- Empty input: empty output, no crash
- "hello world" (component) → "hello%20world"; "a&b" → "a%26b"; "a?b" → "a%3Fb"; "a#b" → "a%23b"; "100%" → "100%25"
- Arabic "السلام" → "%D8%A7%D9%84%D8%B3%D9%84%D8%A7%D9%85"; emoji 🎉 → "%F0%9F%8E%89"
- Whole URL "https://example.com/search?q=hello world&lang=ar" (encodeURI) → "https://example.com/search?q=hello%20world&lang=ar" (structure intact)
- Decode "%D8%A7%D9%84%D8%B3%D9%84%D8%A7%D9%85" → "السلام"; "%2520" → "%20"
- 20,000-character input (5,000 repeats of "a b ") → 40,000 characters out, no crash
- Malformed decode ("100%") throws URIError, caught by the page and shown as a plain message
- Double-encoding warning regex fires on "%20" input, not on plain text
