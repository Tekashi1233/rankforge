### Important

1. **Two long meta descriptions (fixed).** Canonical URL Generator 176 chars, Robots.txt
   Generator 162 chars. Google truncates these in snippets.
2. **One post just under 800 words (fixed).** The new canonical-URL guide was 774 words
   (whole-page count). It is now 917 after a new FAQ section.
3. **www URLs still take 2 hops (open — needs the owner).** The pre-existing Cloudflare
   dashboard Redirect Rule for www fires before the Worker and only fixes the host, so
   `https://www.rankforgetool.com/tools/word-counter.html` goes www-rule → Worker → canonical.
   Verified live this week. The rule is now redundant (the Worker handles www→apex itself);
   removing it in the Cloudflare dashboard (Rules → Redirect Rules) would make every URL
   one hop. The read-only Cloudflare token cannot remove it (403). Only affects www URLs,
   which the site never links to.

## Method notes

- Audit scripted in Python (`~/workspace/goals/rankforge-weekly-audit/hidden_files/audit-2026-11-13.py`):
  per-page title/meta/canonical/OG/Twitter/heading/image/footer/JSON-LD extraction for all 49
  pages with `html.parser` (real JSON-LD blocks only — tool JavaScript strings are not parsed);
  sitemap vs file inventory; RSS vs `datePublished`; word counts; internal-link target
  resolution (relative hrefs resolved); duplicate-content Jaccard similarity; `curl -I` live
  checks for home, sitemap, RSS, robots.txt, ads.txt, llms.txt, one tool, one blog post,
  both external hosts, and redirect hop traces for `.html`, `http://` and `www` variants.
- Word counts include navigation/footer text, so article text alone is shorter than the
  figures quoted; the "under 800 words" flag is therefore conservative.
- No facts, statistics or tool features were invented. All new copy is original and derived
  from the site's own existing text.
