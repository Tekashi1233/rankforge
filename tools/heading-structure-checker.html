Why heading structure matters

Headings (H1 through H6) create the outline of a page. Search engines and AI systems use that outline to understand topics and subtopics. Screen readers rely on it for navigation. A clear hierarchy also helps human readers scan the page.

Common problems this tool catches

  • Missing H1 — every page should have exactly one main H1 that states the primary topic.
  • Multiple H1s — can dilute the main topic signal.
  • Skipped levels — jumping from H1 to H3 (or H2 to H4) without the intermediate level confuses both users and machines.
  • Out-of-order levels — headings that decrease then increase inconsistently.

Fixing these issues is one of the simplest on-page SEO and accessibility wins you can make.

How to use this Heading Structure Checker

  1. Paste the page HTML into the box, or paste plain text that uses Markdown-style headings (# for H1, ## for H2, and so on).
  2. Click Analyse headings. The checker lists every heading in order, counts the H1 tags, and flags skipped levels.
  3. Fix the flagged issues first: add a missing H1, remove extra H1 tags, then fill in any skipped levels.
  4. Paste the updated HTML and analyse it again to confirm the outline is clean.

Frequently asked questions

How many H1 tags should a page have?

Exactly one. The H1 should state the main topic of the page and usually matches the title tag. Extra H1 tags dilute that signal, so demote styling-only headings to H2 or lower.

Does skipping a heading level hurt SEO?

It can. A jump such as H1 straight to H3 breaks the page outline, which makes the topic structure harder for search engines, AI answer engines and screen readers to follow. Add the missing level instead of skipping it.

Can I check Markdown headings as well as HTML?

Yes. If no HTML headings are found, the checker reads Markdown-style headings instead: one hash (#) is H1, two hashes (##) are H2, and so on up to six hashes.

What should I fix first?

Start with the H1: add one if it is missing, or keep only one if there are several. Then fix skipped levels, working from the top of the page down, and re-check the outline after each edit.
