What makes a strong password?

A strong password is long, unpredictable, and unique to each account. Modern guidance from security experts emphasizes length over complexity rules. A 16-character random password that mixes upper and lower case letters, numbers, and symbols is vastly harder to crack than a short password that merely satisfies “one capital, one number, one symbol” checkboxes.

Think of it as a combination lock. A short password is a lock with few dials, so there are not many combinations to try. Every character you add is another dial, and every character type you allow makes each dial bigger. That is why a 16 character password is not twice as strong as an 8 character one. It is stronger by a factor that grows with each character, which is why length does most of the work.

Why generating passwords in the browser matters

Many online generators send your request to a server. This tool creates passwords entirely on your device using the browser’s built-in cryptographic random number generator (crypto.getRandomValues). Nothing is transmitted or stored. That makes it suitable for creating credentials for email, banking, admin panels, and other sensitive accounts.

Best practices for password security

  • Use a unique password for every important account.
  • Prefer length (16–64 characters) over forced complexity.
  • Store passwords in a password manager rather than a spreadsheet or notes app.
  • Enable multi-factor authentication (MFA) wherever it is available.
  • Change a password immediately if a service reports a breach.
  • Avoid personal information, dictionary words, or keyboard patterns.

Length or complexity: what matters more

When people hear "strong password", they often picture a short string packed with symbols, something like P@ssw0rd! It looks secure, but it is short, it follows a pattern everyone knows, and it appears in password lists used by attackers. Length beats that kind of complexity. A 16 character password made only of lowercase letters has far more possible combinations than an 8 character password that uses every character type, because each extra character multiplies the total.

Forced complexity rules make this worse. When a site demands a capital, a number and a symbol, most people add them in the same predictable places: a capital at the start, a number at the end, an exclamation mark after that. Attackers know these habits and try them first. The better habit is simple: make the password long and random, then add variety on top of that. Use the generator with all four character types switched on and the length set to 16 or more, and you get both.

A worked example: three accounts, three settings

The right settings depend on the account. Here is how one person might use the generator for three different accounts.

  • Email account: length 20, all four character types on. Your email is the key to password resets everywhere else, so give it the longest password you will store in a manager.
  • Online banking: length 20 to 24, all four types on, if the bank accepts symbols. Some banks limit length or block certain symbols, so generate the password, then check it is accepted before you save it anywhere.
  • A throwaway forum account: length 16, letters and numbers only, no symbols. Some older sites reject symbols, and a 16 character random password is still far stronger than anything a person would invent.

In each case, generate a fresh password, paste it into your password manager, and only then save it on the site. That order matters: if you save it on the site first and lose the tab, you have to start over.

Common password mistakes

  • Reusing one password with small changes, like adding a 1 or the year for each site. Once one version leaks, attackers try the variations.
  • Building passwords from personal details: pet names, birthdays, favourite teams. These are the first things an attacker guesses, and much of it is public on social media.
  • Using keyboard patterns such as qwerty, 1qaz2wsx or abcd1234. They look random at a glance but appear in every common password list.
  • Writing passwords in a notes app, a spreadsheet or on paper stuck to a monitor. A password manager encrypts them and fills them in for you.
  • Sharing a password over email or chat. If someone else needs access, use the service's own sharing feature or a password manager's share option.
  • Changing passwords on a schedule for no reason. Rotating a strong, unique password every 90 days adds little. Change it when there is a breach or a reason to suspect it leaked.

Storing passwords without memorising them

Nobody can memorise a different 20 character random password for every account, and nobody should try. That is the whole point of a password manager: it remembers them, fills them in, and warns you when a password appears in a known breach. Pick one reputable manager, set it up on your phone and computer, and protect it with a strong master password plus multi-factor authentication.

Your master password is the one password worth memorising, so make it a long passphrase of four or five random words, and write it down on paper kept somewhere safe at home as a backup. If you are not ready for a manager yet, the next best step is still to use unique generated passwords and store them somewhere only you can reach, never in plain text on a shared computer. But a manager is the habit that makes everything else easy, so treat it as step one rather than step ten.

Frequently asked questions

Are these passwords really random?

Yes. They use your browser's built-in cryptographic random number generator.

Is it safe to generate passwords online?

Here, yes, because nothing leaves your device. Still, store passwords in a reputable password manager.

How long should a password be?

At least 12 characters, and 16 or more is better. Use a different password for every account.

Should I include symbols?

Yes when the site allows them. Symbols increase the number of possible combinations and make brute-force attacks slower.

Can I use the same generated password on two sites?

No. A generated password is only strong if it is unique. If one site leaks it, attackers will try it on your email, banking and social accounts. Generate a fresh one for every account.

What if a site will not accept symbols?

Turn symbols off and increase the length instead. A 20 character password using only letters and numbers is still very strong. Check the site's rules first, then generate a password that fits them.
