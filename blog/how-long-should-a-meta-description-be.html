How Long Should a Meta Description Be? (With Examples)

A meta description is the short summary that can appear under your page title in search results. It does not directly make a page rank higher, but a clear, appealing description can persuade more people to click your result, and that matters. The most common question is how long it should be. This guide gives a practical answer, plus examples you can copy.

The short answer

Aim for roughly 120 to 160 characters. Google does not set a fixed limit, because snippets are cut by pixel width rather than character count, but descriptions longer than about 155 to 160 characters are often shortened with an ellipsis on desktop, and mobile results can cut off sooner. Putting the most important information in the first 120 characters is a safe habit.

Google may rewrite your description

Search engines often replace your description with text taken from the page when they think it matches the search better. That is normal. You cannot control it fully, but a well-written description is still used often, especially when it accurately reflects the page and the query.

How to write a good meta description

  • Summarize the page honestly. Tell readers what they will get. Misleading descriptions raise bounce rates.
  • Include your main keyword naturally. Search engines bold matching words, which helps your result stand out.
  • Lead with the benefit. Say what problem you solve before you describe how.
  • Add a gentle call to action. Words like "learn", "compare" or "see examples" work well.
  • Make each one unique. Duplicate descriptions across pages waste the opportunity.

Good and bad examples

Bad: "Meta description. SEO, SEO tools, free SEO, best SEO tool, SEO generator online." This is a keyword list, not a sentence, and nobody wants to click it.

Good: "Learn the ideal meta description length, how Google shortens snippets, and how to write descriptions that earn more clicks." It is clear, specific, and about 130 characters.

Bad: "Welcome to our website. We are a company that offers many services. Click here to learn more about us and what we do for customers." It is vague and says nothing useful.

Good: "Free online word counter that tracks words, characters and reading time instantly. No sign-up needed." It names the benefit and removes a worry.

Common mistakes

  • Leaving the description empty and letting search engines pick random text.
  • Copying the page title as the description.
  • Using double quotation marks inside the tag, which can break the HTML. Use single quotes or none.
  • Stuffing keywords instead of writing for a person.

Conclusion

Keep your meta description between about 120 and 160 characters, write it for a human, and give each page its own. It is a small piece of text with an outsized effect on whether searchers choose you.
