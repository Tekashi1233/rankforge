Tool FAQ
Common questions
Will valid JSON-LD guarantee a rich result?
No. Correct syntax is only one requirement; search engines decide eligibility and what to display.
Should I mark up content visitors cannot see?
Do not use this tool to describe hidden or inaccurate content. Keep structured data consistent with the visible page.
Which type should I choose?
Choose the type that genuinely describes the page, and only fill fields you can support with accurate information.
