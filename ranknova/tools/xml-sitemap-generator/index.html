Tool FAQ
Common questions
Does listing a page guarantee indexing?
No. A sitemap helps discovery but does not force a crawl or inclusion in search results.
Which URLs belong in my sitemap?
Use preferred, public canonical URLs that you want search engines to consider. Exclude redirects and pages intentionally set to noindex.
Are my pasted URLs uploaded?
No. URL validation and XML generation happen locally in your browser.
